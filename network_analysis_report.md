
# Network Traffic Analysis Report

## 1. Introduction
This project demonstrates basic network traffic
analysis using Wireshark.

## 2. Objectives
- Capture live network packets.
- Understand DNS traffic.
- Analyze TCP handshake.
- Observe HTTP and TLS traffic.
- Identify IP addresses and ports.

## 3. Tools
- Wireshark
- Windows CMD

## 4. Analysis
DNS: Analyzed DNS queries and responses.

TCP: Observed TCP connection establishment.

HTTP: Observed HTTP requests.

TLS: Observed TLS handshake traffic.

IP: Identified source and destination IP addresses.

## 5. Conclusion
This project helped me understand basic
network communication and packet analysis.
